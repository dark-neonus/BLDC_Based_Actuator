# Glossary

| Term | Meaning |
|------|---------|
| **ABZ / ABI** | Incremental encoder outputs: two quadrature signals (A, B) + index pulse (Z/I) once per turn |
| **ADC** | Analog-to-digital converter |
| **Back-EMF** | Voltage generated by the spinning motor, proportional to speed |
| **BLDC / PMSM** | Brushless DC motor / permanent-magnet synchronous motor (sinusoidal back-EMF). Your WK8110 behaves as a PMSM. |
| **Body diode** | Parasitic diode inside every MOSFET, source -> drain |
| **Bootstrap** | Capacitor + diode trick that supplies the high-side gate driver |
| **Bulk capacitance / DC link** | Big capacitors on the DC bus supplying ripple current |
| **CAN / CAN-FD / TWAI** | Differential multi-drop robot bus; FD = flexible data rate; TWAI = Espressif's name for its CAN controller |
| **CC pins** | USB-C configuration channel pins; 5.1 kΩ pull-downs identify a device (sink) |
| **Center-aligned PWM** | Timer counts up then down; edges symmetric; sampling at the valley is clean |
| **Clarke / Park transform** | Math converting 3-phase currents into 2-axis stationary (α,β) and then rotating (d,q) frames |
| **CMRR** | Common-mode rejection ratio: how well an amplifier ignores voltage common to both inputs |
| **Cogging** | Torque ripple from magnets attracting to stator teeth, present even with no current |
| **Creepage / clearance** | Distance along the surface / through air between conductors at different voltages |
| **CSA** | Current-sense amplifier |
| **Dead time** | Delay between turning one FET of a half-bridge off and the other on |
| **DC-bias derating** | Capacitance loss of ceramic (X5R/X7R) capacitors under DC voltage |
| **dI/dt, dV/dt** | Rate of change of current / voltage - the source of most switching noise |
| **ENOB** | Effective number of bits of an ADC, including noise |
| **ESD** | Electrostatic discharge |
| **ESR / ESL** | Equivalent series resistance / inductance of a capacitor |
| **FOC** | Field oriented control |
| **Gate charge (Qg, Qgd)** | Charge needed to switch a MOSFET; Qgd = Miller charge |
| **Half-bridge** | Two series switches (high side, low side) with the output in the middle |
| **Holding brake** | Electromagnetic brake that locks the shaft when unpowered |
| **Id / Iq** | Direct-axis (flux) and quadrature-axis (torque) currents in FOC |
| **IDRIVE** | Programmable gate-drive current in TI smart drivers |
| **Kelvin connection** | Separate sense traces from the exact pads of a shunt, carrying no load current |
| **Kt / Kv / Ke** | Torque constant (N·m/A) / speed constant (rpm/V) / back-EMF constant |
| **LDO** | Low-dropout linear regulator |
| **MCPWM** | ESP32's motor-control PWM peripheral |
| **Miller plateau** | Flat part of Vgs during switching when Cgd is being charged |
| **MIT mode** | Actuator command τ = Kp·(θd-θ) + Kd·(ωd-ω) + τff |
| **MLCC** | Multi-layer ceramic capacitor |
| **nFAULT** | Active-low fault output (n = active low) |
| **NTC** | Negative-temperature-coefficient thermistor |
| **OCP / OVP / UVLO** | Over-current / over-voltage protection / under-voltage lockout |
| **Pole pairs (p)** | Number of N-S magnet pairs on the rotor; θe = p·θm |
| **Rds(on)** | MOSFET on-resistance |
| **Regen / bus pumping** | Energy flowing from the motor back into the DC bus, raising its voltage |
| **RS-485** | Differential UART-based multi-drop bus |
| **Shoot-through** | Both FETs of a half-bridge on at once -> short circuit |
| **Shunt** | Low-value precision resistor for measuring current |
| **Snubber** | RC (or RCD) network that damps ringing |
| **SOA** | Safe operating area of a transistor |
| **Strapping pins** | MCU pins sampled at reset to choose boot mode etc. |
| **SVPWM** | Space-vector PWM: duty-cycle computation using ~15 % more bus voltage than sine PWM |
| **SWD / JTAG** | Debug/programming interfaces (SWD for ARM; JTAG for ESP32 via USB) |
| **Switch node** | The half-bridge output; swings between 0 and Vbus at each PWM edge |
| **Termination** | 120 Ω resistor at each end of a CAN/RS-485 bus to stop reflections |
| **Thermal via** | Via used to conduct heat between layers |
| **TVS** | Transient voltage suppressor diode |
| **USB Serial/JTAG** | ESP32-S3's built-in USB device that provides a serial port and JTAG without a bridge chip |
| **Zener** | Diode with a defined reverse breakdown voltage, for small-current clamping |
